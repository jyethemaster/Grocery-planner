# Weekly Grocery Planner

Standalone web app (PWA). Pick recipes, set servings, get a grouped shopping list.

## Put it on GitHub
1. Create a **new repository** (e.g. `weekly-grocery-planner`), public.
2. Upload everything in this folder (keep the `icons` folder): `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`.
3. Repo → Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
4. After a minute your app is at `https://YOUR-USERNAME.github.io/weekly-grocery-planner/`

## Install on your phone
- iPhone: open the link in Safari → Share → Add to Home Screen.
- Android: open in Chrome → menu → Install app / Add to Home screen.

## Updating later
Replace `index.html` in the repo, and change `VERSION` in `sw.js` (e.g. `-v2`) so phones pick up the new copy.
