Import & export

One row per ingredient, with columns Recipe, Servings, Ingredient, Amount, Unit, Type. Servings only needs filling in on a recipe’s first row. Type is the shop section and can be left blank, in which case the planner guesses it. Recipes with the same name are replaced. Imported recipes start unticked, so you choose your week.

Export saves every recipe in the same layout as the Excel template (grocery-recipes.xlsx). Edit it in Excel if you like, or open the planner on another device and import that file.
